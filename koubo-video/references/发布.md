# 发布

授权与确认按 SKILL.md 的「发布」一节执行；用户自己的平台和发布方式写在 `我的规则.md`。本文件只讲怎么操作。

## 不自动发布时（默认）

把下面这份清单交给用户，让他自己发：

- 每个平台用哪个视频文件（普通版 / 日记版）、哪张封面（写完整路径）；
- 标题（各平台的字数限制内）、简介、话题；
- 提醒：不显示位置；标题、简介、话题里不出现其他平台的名字。

## 需要的工具

自动发布要用能操作网页、并且能复用用户登录状态的浏览器工具。推荐 **ego-browser**（ego lite 浏览器，https://lite.ego.app/ ，Mac 和 Windows 都有）：

- 检查有没有装：`setup.py check` 的最后一行，或者运行 `ego-browser skill`。
- 没装时：按官方给 AI 的安装说明来：https://github.com/citrolabs/ego-lite/blob/main/skills/ego-browser/references/install.md （下载地址会随版本变，以官方说明为准，不要自己拼）。
  - **Mac**：官方仓库里有安装脚本 `skills/ego-browser/scripts/install.sh`，会下载、装进「应用程序」并打开 ego lite，可以征得用户同意后直接帮他运行。
  - **Windows**：没有安装脚本。请用户打开 https://lite.ego.app/ 下载安装包运行（弹出 SmartScreen 时点「更多信息」→「仍要运行」）。
  - **国内网络**：安装包放在亚马逊 AWS 的 CDN（cdn.ego.app）上，国内一般能直接下载，只是速度不稳定；下载失败或很慢，请用户开代理后重试。
  - 第一次打开要完成引导（可以从 Chrome 导入登录状态，引导会注册 `ego-browser` 命令），这一步必须用户自己在窗口里点完；完成后重开 Codex 或终端。
- 装好后先运行 `ego-browser skill`，读它自己的使用说明，再按下面的平台要点操作。
- 请用户先在 ego lite 里登录要发布的各个平台的创作者后台。

## 发布前

- 复核：账户是预期的账户；视频版本、封面和平台对应；标题、简介是本次的内容。
- `verify.py` 必须全部通过（WARN 要写进发布清单）。
- 登录可能在制作过程中过期，上传前重新确认一次，不能用开剪前的检查代替。
- 登录失效时，有一键登录按钮（比如视频号的「微信快捷登录」）就自己点；点完后网页或电脑上的微信弹出「允许」「确认」也自己点。只有必须扫码或输入密码时，才请用户处理。

## 填写

- **不显示位置**：视频号选「不显示位置」；小红书和抖音不添加地点。不要因为网站推荐了地点就选上。
- **文案风控**：标题、简介、话题里不出现其他平台的名字（微信、抖音、B站等）。
- 平台对标题字数有限制时，缩短展示用的标题，完整意思放进正文。
- 平台页面经常改版：每次重新观察页面，不要照搬上次的控件位置或坐标。

## 视频号

- 上传视频完成前「编辑封面」点不开（提示「文件上传中」），要等进度条消失；上传进度可能在 shadow DOM 里，普通的页面文字读不到「取消上传」。
- 封面：点「编辑」→ 右下「上传封面」→ 滚到弹窗底部点「确认」，提示「封面已更新」才算成功。横版视频点「编辑」可能先弹「使用此素材作为封面？」，选「直接编辑」。
- 描述框是 contenteditable：先用鼠标点进框，再输入文字。
- **短标题不能有逗号等符号**，只允许书名号、引号、冒号、加号、问号、百分号、摄氏度；逗号用空格代替。
- 位置默认是定位城市，要点开选「不显示位置」。
- 发表后列表第一条先显示「处理中」，按实际看到的状态记录。
- 「修改描述和封面」只能改一次、不可撤回，视频上会显示修改记录，改之前想清楚。

## 小红书

- 正文编辑器是 tiptap：段落之间只用一个换行（两个换行会变成两个空段）。
- 话题：每个话题前先把光标移到正文末尾（Mac 上 `Meta+ArrowDown`），再输入 `#话题`、等联想出现后回车；连续直接输入时光标会跑到正文中间，吞掉末尾的字。最后读一遍正文核对。
- 小红书会自动给笔记关联活动，和内容无关时，发布前点「取消关联」。
- 创作者后台能打开不代表能上传：上传走的是另一个域名，进度一直 0%、约 80 秒后报「网络异常」就是上传域名不通。先发别的平台，等一会儿再试；等 20 分钟还不行就告诉用户，不要改用户的网络设置。
- 发布后改封面：笔记管理 → ✏️ → 编辑封面 → 发布。

## 抖音

- 竖封面上传后点「完成」有时不生效：关掉弹窗重开，确认编辑器里显示的是上传的封面再点「完成」，回到主页面核对缩略图。
- 简介填完后表单会变长，按旧坐标点击会点错（比如点到官方活动的「添加」）：用文字选择器找「选择封面」等按钮；弹窗里的「完成」在视口下方时先滚动到可见再点。
- 话题最多 5 个。
- 发布后换封面：编辑作品 → 换横 / 竖封面 → 提交修改（进入修改审核，视频照常播放）。

## B 站

- 上传按钮和封面上传框有时对直接设置文件没反应，改为点击按钮、等文件选择框再选文件。
- 分区和自动带的标签会变（自动推荐的标签要逐个点 × 删掉）；话题专用的标签不能自定义添加，换成推荐标签。
- 封面同时要 16:9 和 4:3：竖版视频把 3:4 封面用 `cover.py fit --ratio 16:9 --mode pad` 做成 16:9，勾「双比例同步改动」后上传 16:9 版，4:3 居中裁切正好完整。
- 创作声明可以勾「内容为自制：未经作者允许，禁止转载」。
- 评论框输入换行会把后面的内容吞掉，评论写成一行。

## 置顶评论

视频号「评论管理」→ 写评论 → 评论右下「…」悬停出「置顶」；B 站评论「⋮」→「设为置顶」。小红书、抖音网页端没有置顶，只能在手机 App 里操作，告诉用户。

## 提交与核实

- 上传失败可以诊断后重试。提交后结果不明时，先去作品管理列表查，避免重复发布。
- 已发布的作品不会因为本地重新导出而自动更新；改了旧成片时，先查平台是否支持替换，不要擅自再发一条。
- 发布后到各平台的作品管理页确认新作品和状态，区分「审核中」和「已发布」，只按实际看到的报告。
- 各平台作品管理页显示的时间可能按电脑所在时区，也可能按北京时间，记录时注明。

## 记录

把每个平台的结果写进 `<archive_root>/<日期>/制作发布记录.json` 的 `platforms`：

```json
"视频号": {"account": "…", "title": "…", "video": "<文件名>", "cover": "<文件名>",
           "location": "不显示位置", "status": "审核中/已发布", "time": "<平台显示的时间>"}
```

这份记录用于之后恢复和核对。不要把这一期的发布状态当成下一期的默认事实。
