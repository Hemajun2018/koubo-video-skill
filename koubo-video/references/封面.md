# 封面

默认每期做一张竖版 3:4 封面，所有平台通用；做几张、给哪个平台、什么风格，以 `我的规则.md` 为准。配置 `covers` 里列出的封面全部做好、经 `archive.py` 归档之前，不进入发布。

## 1. 底图：本人照片

- 优先用本次拍的照片（素材文件夹里与视频同一时段的照片）。
- 没拍照片就从成片里截一帧，不要用以前的照片（发型、眼镜、衣服、场景都对不上）：

  ```bash
  py S/frames.py --video W/cut.mp4 --out W/cover                # 均匀抽 12 帧拼成一张图，先看大致哪段好
  py S/frames.py --video W/cut.mp4 --out W/cover --around 12.3  # 在 12.3 秒前后每 0.1 秒抽一帧细挑
  py S/frames.py --video W/cut.mp4 --out W/cover --at 12.4 --fix-skin   # 导出这一帧原图
  ```

  挑**眼睛看镜头、闭着嘴略带笑意、没在眨眼**的一帧，不要选说话时张着嘴的。室内暖光、肤色发黄时加 `--fix-skin`（去黄提亮）。

## 2. 参考图（可选）

`setup.py show` 里的 `cover_refs` 文件夹放用户认可的封面样式。参考图只用来参考布局、字体层级、配色和整体风格；参考图里的旧照片、旧标题、旧日期必须全部换成本次内容。

## 3. 生成

### 在 Codex 里：用内置的图片生成

Codex 自带 `imagegen`（用 ChatGPT 账号的额度，不需要 API key）：

1. 用 `view_image` 打开底图和参考图，让它们出现在对话里。
2. 用内置的 image_gen 生成，选竖版尺寸，提示词按下面的要点写；明确要求**人脸和标题文字都放在画面中间，上下各留出约 8% 的空白**，方便裁成 3:4。
3. 把生成的图片从 Codex 的默认位置复制到 `W/cover/`，再裁成平台需要的比例：

   ```bash
   py S/cover.py fit <生成的图片> --out W/cover/封面.png --ratio 3:4
   ```

   横版位置（比如 B 站的 16:9）用 `--ratio 16:9 --mode pad`：整张封面居中，两边用模糊的暗色底补齐。

### 没有内置生图的环境（例如 Claude Code）

- 有浏览器自动化工具时，可以打开 ChatGPT 网页，上传底图和参考图生成（操作要点见 [踩坑.md](踩坑.md) 的「ChatGPT 网页」）。
- 都没有时：把底图、参考图和写好的提示词交给用户，请他在 ChatGPT 里生成后把图片放回 `W/cover/`。

## 4. 提示词要点

- **人物**：保持本人的脸、发型、眼镜、衣服不变，一眼能认出是本人。肤色自然白净，不要发黄、蜡黄、发灰、偏橙；正面柔光补光；适度美颜、去暗沉和黑眼圈，但不要过度磨皮，不要网红脸；眼神有神，自然微笑。
- **文字**：封面上的每个中文字逐字写进提示词，要求「文字必须完全一致，不能有错字」。标题尽量短（建议 12 字以内），越短越不容易出错字。
- **风格**：有参考图时写明「只参考布局、字体层级、配色和风格，不要照搬参考图里的人和字」。
- **日记风格**：封面上的日期和 Day 要和成片顶部的标识一致。

## 5. 检查

生成后逐项看：

- 人像像不像本人；
- 中文有没有错字、漏字、多字；
- 比例对不对（`cover.py` 输出的尺寸）；
- 打开 `_thumb.png`（手机信息流里的大小），标题是否还看得清。

不合格就重新生成，并在提示词里说明哪里不对。

## 风控

封面和标题里不要出现其他平台的名字或 logo（比如在小红书发的封面上出现「抖音」「微信」）。曾经出现过三个平台同时零播放的情况，怀疑和这个有关，虽然没有证实，也当作预防规则。
