# 踩坑记录（遇到异常先查这里）

格式：症状 → 原因 → 现在的做法。已经写进脚本的会注明是哪个脚本。用户自己遇到的新问题记在个人设置里的 `我的经验.md`，不要改这个文件。

## 转写

- **字级时间不准，剪完后半段全部错位**（「以后这玩意儿」丢了开头，结尾整句被截掉）→ whisper 不开 DTW 时，字级时间是把每个分段的时长按字数平均分配的，长句会偏 0.3 到 2 秒 → `transcribe.py` 固定用 `-dtw`，并在新版 whisper.cpp 上加 `-nfa`（开着 flash attention 时 DTW 不出结果，也不报错）。
- **whisper 常把「呃」「嗯」直接吞掉**，表现为 `source.md` 里的 `‹声x›` 间隙；短于 0.35 秒的多半是时间误差，不一定是语气词。
- **长停顿、密集重说的地方，整段转写的时间不可靠**（「第二点呢是…」连说多遍，字级时间全挤在一个点上），还可能漏掉重录 → ≥0.5 秒的 `‹声›` 间隙前后截 4–7 秒单独转写，用 small 模型交叉验证，不要只信整段转写。
- **成片接缝处转写偶尔幻听**（把「不一样」听成「就我今天」）；2 秒内重复的长句多半是听错 → 拿不准的地方用小片段、两个模型复核；还拿不准就在交付时点名请用户听。
- **专有名词识别错**（「Cloud Code」应为「Claude Code」，「实施进度」应为「实时进度」）→ 词典提示不能保证识别正确，字幕校对时按词典修正，新发现的写进个人 `词典.txt`。
- **Windows 上转写不带中文提示词** → whisper.cpp 在 Windows 上按系统编码（中文系统是 GBK）接收命令行参数，中文提示词会变成乱码 → `transcribe.py` 在 Windows 上只传英文词，繁体用 zhconv 转成简体。语气词可能比 Mac 上少，靠 `‹声›` 间隙去找。

## 剪辑

- **剪辑点往后挪会吞进下一个字的开头**（残留「就」）→ `cut.py` 只往前找安静处，往后最多挪 0.02 秒。
- **单字卡顿（「上上午」）两个字之间没有停顿时，怎么剪都会吞音** → 口误规则：保留不剪。
- **音频段和视频段长度不一致，拼接越往后音画越错位** → `cut.py` 把剪辑点对齐到帧，用 trim/atrim + concat 一次编码完成。
- **段数多时视频比音频多几帧**（24 段多了 4 帧，越往后口型越错位）→ trim 起止点按 4 位小数格式化，帧时间舍入导致段首丢帧、段尾多帧 → `cut.py` 视频 trim 起止各减半帧。`cut.py` 时长不符会以退出码 1 结束，命令不要用 `;` 串起来，否则会吞掉报错。
- **loudnorm 会在音频尾部补出约 0.1 秒** → `cut.py` 末尾用 `atrim` 截到预期时长。
- **AAC 编码后峰值超过 0 dBFS** → `cut.py` 在 loudnorm 后加限幅（-3 dBFS）。峰值还在 0 dB 附近时 `verify.py` 只给 WARN。
- 片尾收尾的「好」、开录前的杂音也要剪掉，成片转写能暴露出来。

## 素材

- **日期差一天** → 手机导出或转存的副本（文件名常以 `copy_` 开头），`creation_time` 往往是导出时间而不是拍摄时间；拍摄时间刚过零点时也容易差一天 → `diary_date.py` 写出依据，只靠 `creation_time` 或接近零点时请用户确认。
- **iCloud 文件只是占位，或者手机还在上传** → `prepare.py` 检测到会直接提示并退出，不会读到一半卡住。
- **iPhone 默认录 HDR 视频，直接剪成片会发灰** → `prepare.py` 用 ffmpeg 的 zscale 转成普通 SDR（Windows 的 ffmpeg 自带；macOS 需要 `brew install ffmpeg-full`）；转不了会提示用户关掉 iPhone 的「HDR 视频」，或用微信把视频传到电脑。

## 导出

- **很多 ffmpeg 没有 libass**（不能用 subtitles/ass 滤镜烧字幕）→ `render.py` 用 Pillow 画字幕卡，再用 ffmpeg 一次叠加。
- **英文行用中文字体里的英文字母，字宽和字距会别扭** → 英文行用西文字体（Mac 是 Helvetica Neue，Windows 是 Segoe UI）。
- **Windows 命令行长度上限约 32K 字符** → `render.py` 在工作目录里用相对路径引用字幕卡。
- **日记标识是按 1080×1920 竖版设计的**，直接叠到横版视频上会被拉伸、压住内容 → 横版先只出普通版，问用户要不要标识。

## ChatGPT 网页（没有内置生图、改用浏览器生成封面时）

- 文件输入框有好几个，不能用通用选择器；直接给输入框设置文件有时不报错但附件没挂上 → 走文件选择器：点「添加文件等内容」→ 等文件选择框 → 选文件。**发送前确认附件数量对**（有几个「移除」按钮），不够就重新上传。
- 新开聊天后马上上传，附件可能挂不上 → 填完提示词后再核对一次附件。
- **不要同时在两个标签页里写提示词**：草稿会在标签页之间同步，第二张封面的提示词混进了第一张。一张做完再做下一张。
- 发送用「发送」按钮，按回车或反复重试容易触发人机验证；遇到验证请用户自己点。
- 下载生成图：页面里最后一张图可能是附件的放大层，要按图片说明以「已生成图像」开头来找。

## 网络

- 某个平台后台或 ChatGPT 打不开、上传卡在 0% → 先做别的平台或别的步骤，过一会儿再试；持续 20 分钟以上就告诉用户具体现象。不要擅自修改用户的网络或代理设置。
