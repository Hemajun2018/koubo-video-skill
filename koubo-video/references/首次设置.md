# 首次设置

目标：装好环境，问清用户的习惯，写进配置和 `我的规则.md`。用大白话和用户交流，一次只问一两件事，每个问题都给出默认答案，用户说「默认就行」就用默认。

## 1. 装环境

1. 运行 `py S/setup.py check`，看缺什么。
2. 有 ✗ 就运行 `py S/setup.py install`。它要联网下载 ffmpeg、whisper 和语音识别模型（1.6–3 GB），大约 10–30 分钟。在 Codex 里运行时会请求联网和写入 `~/.koubo-video` 的权限，请用户同意。
   - **macOS 没有 Homebrew**：install 会提示。请用户打开「终端」，粘贴 https://brew.sh 首页的那一行安装命令运行（中途要输入开机密码），装好后再运行 install。
   - **Windows 没有 Python**：请用户在 PowerShell 里运行 `winget install Python.Python.3.12`（或到 python.org 下载安装，勾选「Add python.exe to PATH」），然后重开 Codex。
   - **模型下载失败**：脚本会自动换国内镜像（hf-mirror.com）。还是失败，就告诉用户错误信息，请他检查网络；也可以手动下载 `ggml-<模型名>.bin` 放进 `setup.py show` 里的 `model_dir`。
   - **GitHub 下载失败**（Windows 的 ffmpeg 和 whisper 从 GitHub 下载）：多半是网络问题，请用户换个网络或开代理后重试。
3. 再运行一次 `check`，除了 ego-browser 那一行（可选）都是 ✓ 才算装好。

模型怎么选：Apple Silicon 的 Mac 默认 `large-v3`（最准，有 GPU 加速）；Windows 和 Intel Mac 默认 `large-v3-turbo`（只用 CPU，快好几倍，中文准确度略低）。电脑很慢时可以 `setup.py install --model small`。

## 2. 问用户

1. **工作文件夹放哪？** 默认 `~/口播`（Windows 上是 `C:\Users\<用户名>\口播`；C 盘空间紧张可以放到 D 盘）。剪辑底稿、成品、个人设置都在里面。建议用户以后就在这个文件夹里打开 Codex，这样读写文件不用反复确认权限。
2. **手机录的视频怎么传到电脑？** 默认放进 `<工作文件夹>/素材`。iCloud、OneDrive、微信文件传输、隔空投送都可以；用户有固定的同步文件夹（比如 iCloud 云盘里的某个文件夹）时，就把素材文件夹设成它。
   - 顺带提醒：iPhone 默认录「HDR 视频」，脚本会尽量自动转成普通视频；提示转不了时，可以在 iPhone「设置 → 相机 → 录制视频」里关掉「HDR 视频」。
3. **字幕要中英双语，还是只要中文？** 默认中英双语。
4. **要不要在视频顶部加「视频日记 + 日期 + Day N」标识？** 默认不要。要的话再问：哪天算 Day 1（或者某一天是第几天）。日期按哪个时区算（默认北京时间）。
5. **封面**：每期做几张、给哪些平台用？默认一张 3:4 竖版封面，所有平台通用。有喜欢的封面样式，就把参考图放进 `<工作文件夹>/设置/封面参考/`。
6. **发布**：发到哪些平台？自己手动发，还是让 AI 自动发？默认自己发，AI 把文件和文案整理好。要自动发布的话见 [发布.md](发布.md) 里的「需要的工具」。

## 3. 写配置

```bash
py S/setup.py init --workspace <工作文件夹> [--inbox <素材文件夹>] [--no-english] \
    [--diary-anchor 2026-01-01:1] [--covers 封面] [--labels diary=日记版,plain=成片]
```

- `--covers`：每期必须做的封面名，逗号分隔。只要一张就是 `封面`；多张比如 `视频号,小红书抖音`；不做封面传 `--covers ""`。
- `--labels`：成片文件名末尾的标签，例如 `diary=视频号,plain=小红书抖音`。
- `init` 会建好文件夹，并在 `<工作文件夹>/设置/` 放好 `我的规则.md`、`我的经验.md`、`词典.txt` 三个模板；已经存在的文件不会覆盖。
- 之后要改哪一项，再运行一次 `init` 只带那个选项即可。

## 4. 填「我的规则.md」

把第 2 步问到的答案写进 `我的规则.md`（平台、封面张数和风格、发布方式），尽量用用户的原话。再问一句：平时常说的专有名词、人名、产品名有哪些？写进 `词典.txt`，转写会更准。

## 5. 告诉用户以后怎么用

- 把视频放进素材文件夹，在 Codex 里说「剪一下最新的口播视频」即可。
- 第一次剪完请他看成片，不满意的地方直接说，你会记进 `我的规则.md`，下次照做。
- 更新这个 skill：删掉旧的 skill 文件夹后重新安装即可，个人设置都在工作文件夹里，不受影响。
